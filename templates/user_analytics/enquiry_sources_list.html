Enquiry Sources

Links use a non-readable token (?ref=...). Share the link; users cannot tell which source it is. You identify sources by name here.

With a shared DB, visits from any server appear here. If both stay 0, ensure the server that serves the link (e.g. topteen.in) has the latest code and that ?ref= is not stripped by nginx/proxy.

Add Enquiry Source
  1. Pick a source above and copy its full link (e.g. http://localhost:8002/...?ref=TOKEN).
  2. Verify the token: open Test ref, then add ?ref=YOUR_TOKEN to the URL (e.g. .../test-ref/?ref=U14fSkYzV50). You should see "found": true and current counts.
  3. Open a link that returns 200 with ?ref=TOKEN. E.g. http://localhost:8000/ref-landing/?ref=YOUR_TOKEN (or your runserver port). Use a new incognito/private window so you get a new session.
  4. Come back here and refresh this page. Page views and Sessions for that source should increase by 1.
  5. If they stay 0: (1) Confirm the link you opened is the one from this table and includes ?ref=.... (2) Ensure your runserver is the same app that has the analytics middleware and enquiry ref lookup. (3) Check server logs for Enquiry ref= to see if the token was recognized.
