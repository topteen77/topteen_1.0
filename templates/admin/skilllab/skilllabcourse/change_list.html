    How to Add a Skill Lab Course

    For full courses with sections, worksheets, and MCQs, the script import path is recommended.

    A. Import from Word Documents (Script)

    1. Place DOCX files under SKILLLAB_SOURCE_DIR/<Course Name>/ (intro, index, chapter folders with worksheet.docx).
    2. python scripts/skilllabcourses_script/process_skilllab_courses.py --course "Your Course Name"
    3. (Optional) python scripts/skilllabcourses_script/generate_course_json.py --course "Your Course Name"
    4. python scripts/skilllabcourses_script/upload_skilllab_courses.py --course "Your Course Name" --dry-run
    5. python scripts/skilllabcourses_script/upload_skilllab_courses.py --course "Your Course Name"
    6. python manage.py generate_skilllab_course_images --course-name "Your Course Name"
    7. Verify at /skilllabcourse/course_learning/<slug>/

    B. Add Manually (This Django Admin)

    1. Add Skill lab course — fill name, category, image, price, status, intro/index HTML.
    2. Skill lab course chapters — link chapters to the course.
    3. Skill lab chapter sections — add Introduction, Section 1, 2… in order (required for learning UI).
    4. Skill lab course activities — worksheets (type Worksheet) with PDF upload.
    5. Skill lab MCQs — add MCQ, questions, and answers per chapter.
    6. Set object status to Active and preview on the frontend.
