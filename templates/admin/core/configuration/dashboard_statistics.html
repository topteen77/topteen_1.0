Dashboard Statistics

  • Level Bands — Define level names and minimum points. Values must match cumulative milestones from point rules (starting at account registration).
  • Point Rules — Points awarded per achievement (rule_key). Ordered list with Applies to column for grade-specific rules.
  • Trophy Definitions — What counts as one trophy (rule_key).
  • Streak Config — How streak is computed (UserActivity vs UserEvent).
