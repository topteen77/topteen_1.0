Configure student dashboard statistics: level bands, point rules, trophy definitions, and streak. These drive the four stat cards (Trophies, Points, Streak, Level) on the user dashboard.

Dashboard Statistics

  • Point Rules — Points awarded per achievement (rule_key).
  • Trophy Definitions — What counts as one trophy (rule_key).
  • Streak Config — How streak is computed (UserActivity vs UserEvent).
