SMS or WhatsApp — only one

Choose SMS only or WhatsApp only (or Disabled). Both cannot be active together. Switch providers (SmartPing / Plivo) with the dropdowns — plug-and-play.

If Plivo (or other) numbers are trial/sandbox/testing, set Sender mode → Testing. Those numbers cannot send when the app is in production (ENVIRONMENT=production + DEBUG=False). Use live/upgraded numbers and set Sender mode to Production for customer traffic.
