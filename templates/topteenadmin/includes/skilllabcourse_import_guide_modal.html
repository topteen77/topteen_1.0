How to Add a Skill Lab Course

Choose the method that fits your workflow. For full courses with chapters, worksheets, MCQs, and section-based learning UI, the script import path is strongly recommended.

A. Import from Word Documents (Script)

Use this when you have course content as DOCX files in a folder.

Step 1 — Prepare source folder

Place files under the source directory (override with SKILLLAB_SOURCE_DIR env var if needed):

<SKILLLAB_SOURCE_DIR>/<Course Name>/
├── intro- course.docx   (or intro-course.docx)
├── index.docx
├── chapter_1/
│   ├── chapter1.docx
│   └── worksheet.docx
├── chapter_2/
│   └── ...
└── ...

Step 2 — Process DOCX → HTML / PDF / JSON

From the project root:

python scripts/skilllabcourses_script/process_skilllab_courses.py --course "Your Course Name"

Output is written to skilllabcourses_html/<Course Name>/

Step 3 (optional) — Generate JSON for review

python scripts/skilllabcourses_script/generate_course_json.py --course "Your Course Name"

Step 4 — Upload to database

Dry run first, then upload (creates sections, worksheets, MCQs, and S3 PDFs):

python scripts/skilllabcourses_script/upload_skilllab_courses.py --course "Your Course Name" --dry-run
python scripts/skilllabcourses_script/upload_skilllab_courses.py --course "Your Course Name"

Use upload_skilllab_courses.py (not upload_from_json.py) so chapter sections are created for the learning UI.

Step 5 — Post-import

python manage.py generate_skilllab_course_images --course-name "Your Course Name"

Step 6 — Verify on frontend

  • Course list: /skilllabcourse/
  • Course detail: /skilllabcourse/skilllabcoursedetail/<slug>/
  • Learning UI: /skilllabcourse/course_learning/<slug>/

B. Add Manually (Admin Forms)

Use this for small edits or when you are building a course piece by piece without DOCX files.

Step 1 — Create the course

Click Add Skill Lab Course and fill in name, category, image, price, status, description, Course Introduction, and Course Index HTML fields. Set Status to Active.

Step 2 — Add chapters

Go to SkillLabCourse Chapter → Add. Link each chapter to the course. Add legacy content HTML if you are not using sections.

Step 3 — Add activities (worksheets)

Go to SkillLabCourse Activity → Add. Set type to Worksheet, link to the chapter, and upload the PDF file.

Step 4 — MCQs and sections (Django Admin)

Interactive MCQ quizzes and per-section learning navigation require SkillLabChapterSection and SkillLabMCQ records. Manage those at Django Admin → Skilllab (sections, MCQ questions, and answers are not available in this simplified form yet).

Step 5 — Preview and publish

Use the Preview action on the course list to open the frontend. Confirm the learning page works at /skilllabcourse/course_learning/<slug>/.
