MCQs

Question 1: What is the primary purpose of "game mechanics" in game design?

A) To create the background music for the game

B) To define the rules and systems that make the game function

C) To design the visual art and characters

D) To write the storyline of the game

Correct Answer: B) To define the rules and systems that make the game function

 

Question 2: Which of the following is a key difference between 2D and 3D game development?

A) 2D games always have better graphics than 3D games

B) 3D games include depth and allow movement in all directions, while 2D games are flat

C) 2D games require more powerful computers than 3D games

D) 3D games cannot be made with free tools like Unity

Correct Answer: B) 3D games include depth and allow movement in all directions, while 2D games are flat

 

Question 3: How does Augmented Reality (AR) differ from Virtual Reality (VR)?

A) AR fully immerses you in a digital world with a headset, while VR uses a phone screen

B) AR overlays digital elements onto the real world, while VR creates a completely virtual environment

C) VR is only used for gaming, while AR is only for education

D) AR requires no technology, while VR needs expensive equipment

Correct Answer: B) AR overlays digital elements onto the real world, while VR creates a completely virtual environment

 

Question 4: What is a key advantage of using Scratch for beginner game developers?

A) It requires advanced coding knowledge in C#

B) It allows for drag-and-drop coding without typing complex code

C) It is only used for creating 3D games and VR experiences

D) It is a paid tool with professional-grade features

Correct Answer: B) It allows for drag-and-drop coding without typing complex code

 

Question 5: When designing a simple game as part of a hands-on activity, what is an important step to ensure the game is playable?

A) Focus only on creating detailed graphics before testing

B) Test and tweak the game to balance difficulty and fix bugs

C) Make the game as complex as possible to impress others

D) Avoid sharing the game with peers for feedback

Correct Answer: B) Test and tweak the game to balance difficulty and fix bugs
