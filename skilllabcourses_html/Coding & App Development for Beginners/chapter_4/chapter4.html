Chapter 4: Building Logic with Algorithms and Flowcharts

 

Section 1: What are Algorithms? Breaking Down Problems

What is an Algorithm?

Imagine you’re trying to solve a Rubik’s Cube or plan a group outing. You don’t just act randomly; you follow a set of steps to reach your goal. In programming, an algorithm is a step-by-step set of instructions to solve a problem or complete a task. Algorithms are like recipes for your computer to follow—they break down complex challenges into simple, actionable steps. They’re not written in a specific programming language; they’re just logical plans.

For high school students, think of algorithms as the way you strategize in a video game. For example:

  • To win a battle in a game, you might think: Choose a weapon → Find the enemy → Attack if health is high → Retreat if health is low. Each step is clear and in order. If you skip a step or mess up the sequence, you might lose the game. Algorithms in coding ensure the computer executes tasks in the right sequence to avoid errors.

Why are Algorithms Important?

Algorithms are the backbone of problem-solving in coding. They help you:

  • Break down big, complicated problems into smaller, manageable pieces.
  • Avoid mistakes by planning your solution before writing code.
  • Make your code efficient (faster and less resource-heavy).
  • Communicate ideas clearly to others, like teammates or teachers, before coding begins.

    •  

     

Real-Life Examples for Teens

  • Organizing a Study Group: Let’s say you’re setting up a study session with friends for a big test. You need an algorithm to plan it:
    • Step 1: Make a list of friends who need help.
    • Step 2: Check everyone’s availability for a common time.
    • Step 3: Decide on a location (library, online, someone’s house).
    • Step 4: Assign topics for each person to explain.
    • Step 5: Send reminders a day before. This is an algorithm—a clear plan to solve the problem of “how to prepare for the test together.”
  • Choosing a Movie to Watch: When deciding on a movie with friends, your algorithm might be:
    • Step 1: List everyone’s favourite genres (action, comedy, horror).
    • Step 2: Eliminate genres no one likes.
    • Step 3: Pick a movie from the remaining genres on a streaming app.
    • Step 4: If everyone agrees, watch it; if not, repeat from Step 2. This decision-making process is an algorithm you use without even realizing it!

Fun Activity: Create Your Own Algorithm

  • Morning Routine Algorithm: Write down every single step of your morning routine before school, from waking up to leaving the house. Be super detailed (e.g., “Turn off alarm clock,” “Put on left sock, then right sock”). Share your algorithm with a friend and see if they can follow it exactly. Did they run into any problems? This shows how important clear, precise instructions are in algorithms!
  • Snack Run Algorithm: Plan a trip to the store to buy snacks for a movie night. Include steps like “Check how much money I have,” “If less than $10, ask parents for more,” and “Pick snacks under budget.” Test your algorithm by pretending to follow it—did you miss any steps?

Deeper Dive: Types of Algorithms

Not all algorithms are the same. Here are a few types you’ll encounter in coding (don’t worry, we’ll keep it simple!):

  • Sequential Algorithms: Steps happen one after another, like a to-do list (e.g., making a sandwich).
  • Conditional Algorithms: Include decisions, like “if this, then that” (e.g., if it’s raining, take an umbrella).
  • Iterative Algorithms: Repeat steps until a goal is reached (e.g., keep guessing a password until it’s correct). These types will come up as we solve problems later in this chapter.

Key Takeaway

An algorithm isn’t code—it’s a plan. It’s your way of telling the computer, “Hey, let’s solve this problem step by step.” Once you have a solid algorithm, turning it into code becomes much easier. Think of it as planning a road trip before you start driving—you’re less likely to get lost!

 

Section 2: Creating Flowcharts for Simple Tasks

What is a Flowchart?

A flowchart is a visual representation of an algorithm. It uses shapes like ovals, rectangles, and diamonds to show the steps of a process and how they connect. Flowcharts are like a map for your program, making it easy to see the “flow” of logic before you start coding. They’re especially useful for spotting where decisions are made or where the process might loop.

Why Use Flowcharts?

  • They help you visualize the steps of your algorithm, making complex ideas clearer.
  • They make it easier to spot mistakes or missing steps before coding.
  • They’re great for explaining your ideas to others (like a teacher, teammate, or even yourself when revisiting a project).
  • They simplify debugging by showing where the logic might go wrong.

Common Flowchart Symbols

Here are the basic shapes you’ll use (think of them as your flowchart “stickers”):

  • Oval: Start or End of the process.
  • Rectangle: A step or action (e.g., “Print a message” or “Add two numbers”).
  • Diamond: A decision point with Yes/No or True/False outcomes (e.g., “Is it raining?”).
  • Parallelogram: Input or Output (e.g., “Get user input” or “Display result”).
  • Arrow: Shows the direction of the flow (connects the shapes).

Example 1: Flowchart for Deciding What to Wear

Let’s create a flowchart for a simple decision teens make every day: “What should I wear based on the weather?”

  • Start (Oval)
  • Check the weather (Diamond: “Is it cold?”)
    • If Yes → Wear a jacket (Rectangle) → End (Oval)
    • If No → Check if sunny (Diamond: “Is it sunny?”)
      • If Yes → Wear a t-shirt and sunglasses (Rectangle) → End (Oval)
      • If No → Wear a light sweater (Rectangle) → End (Oval)

Visual Description (since I can’t draw here):

  • Start in an oval at the top.
  • Arrow down to a diamond labeled “Is it cold?”
  • From the diamond, two arrows split: “Yes” goes left to a rectangle “Wear jacket,” then to an oval “End.”
  • “No” goes right to another diamond “Is it sunny?”
  • From this diamond, “Yes” goes to a rectangle “Wear t-shirt and sunglasses,” then “End”; “No” goes to a rectangle “Wear light sweater,” then “End.”

Example 2: Flowchart for Homework Completion

Here’s another flowchart for something relevant to students: “Should I do homework now?”

  • Start (Oval)
  • Check time (Diamond: “Is it before 8 PM?”)
    • If Yes → Check energy (Diamond: “Am I tired?”)
      • If No → Do homework (Rectangle) → End (Oval)
      • If Yes → Take a short break (Rectangle) → Back to “Am I tired?”
    • If No → Set alarm for tomorrow (Rectangle) → End (Oval)

      •  

Visual Description:

  • Start at the top (oval).
  • Arrow to diamond “Is it before 8 PM?”
  • “Yes” leads to diamond “Am I tired?”; “No” leads to rectangle “Set alarm for tomorrow,” then “End.”
  • From “Am I tired?,” “No” goes to rectangle “Do homework,” then “End”; “Yes” goes to rectangle “Take short break,” then loops back to “Am I tired?”

Practical Explanation for Teens

Flowcharts are like planning a TikTok video or a group chat decision. You decide: “If I get 100 likes, I’ll post a follow-up. If not, I’ll try a different trend.” Mapping this out visually helps you see all possible outcomes before you act. In coding, flowcharts prevent you from writing messy code by showing exactly where decisions and actions happen.

Fun Activity: Draw Your Own Flowchart

  • Survive a Boring Class: Grab a piece of paper and draw a flowchart for “How to survive a boring class.” Include decisions like “Is the teacher looking at me?” and actions like “Doodle in notebook” or “Pay attention.” Use the shapes above and show it to a friend—does it make sense to them?
  • Plan a Weekend Hangout: Create a flowchart for deciding what to do on a Saturday with friends. Include decisions like “Is everyone free?” and “Is the weather good?” with actions like “Go to the mall” or “Play video games online.” Add at least two decision points and three possible outcomes.

Deeper Dive: Loops in Flowcharts

Sometimes, a flowchart includes a loop—repeating steps until a condition is met. In the “Homework Completion” example above, the “Take a short break” loops back to “Am I tired?” until you’re ready to work. Loops are common in coding (like playing a song on repeat until you skip it), and flowcharts help visualize them clearly.

Key Takeaway

Flowcharts turn your thoughts into a picture. They’re a super helpful tool to plan out programs, especially when decisions (like “if this, then that”) or repetitions (loops) are involved. They’re your first step to making sure your logic is solid before coding.

 

 

 

Section 3: Writing Pseudocode to Plan Programs

What is Pseudocode?

Pseudocode is a way to write down your algorithm in plain English (or any language) mixed with some coding-like structure. It’s not real code, so you don’t need to worry about syntax (rules like semicolons or brackets in Python). It’s like a rough draft of your program, helping you plan what your code will do without getting bogged down by technical details.

Why Use Pseudocode?

  • It bridges the gap between your algorithm and actual code.
  • It lets you focus on logic without stressing about coding rules.
  • It’s easy to read and share with others for feedback, even if they don’t know how to code.
  • It helps catch logical errors before you start writing real code.

Example 1: Pseudocode for a Simple Game

Let’s plan a “Guess the Number” game where the computer picks a number between 1 and 10, and the player guesses it.

BEGIN

Set secret_number to a random number between 1 and 10

Set guess to 0

Set attempts to 0

WHILE guess is not equal to secret_number AND attempts is less than 5

Ask player to input a guess

Store input as guess

Increase attempts by 1

IF guess is less than secret_number

Say "Too low, try again!"

ELSE IF guess is greater than secret_number

Say "Too high, try again!"

ELSE

Say "Congratulations, you got it in", attempts, "tries!"

END IF

END WHILE

IF guess is not equal to secret_number

Say "Game Over! The number was", secret_number

END IF

END

 

Example 2: Pseudocode for a To-Do List App

Imagine you’re building a simple app to manage daily tasks for school.

BEGIN

Create an empty list called tasks

Display menu: 1. Add task, 2. View tasks, 3. Mark task done, 4. Exit

Ask user to choose an option

Store choice

WHILE choice is not 4

IF choice is 1

Ask user for task description

Add description to tasks list

Say "Task added!"

ELSE IF choice is 2

IF tasks list is empty

Say "No tasks yet!"

ELSE

Display all tasks with numbers (1, 2, 3, ...)

END IF

ELSE IF choice is 3

IF tasks list is empty

Say "No tasks to mark done!"

ELSE

Ask user for task number to mark done

Remove that task from list

Say "Task marked as done!"

END IF

ELSE

Say "Invalid choice, try again"

END IF

Display menu again

Ask user to choose an option

Store choice

END WHILE

Say "Goodbye!"

END

 

Practical Explanation for Teens

Think of pseudocode as texting a friend about a plan for a group project. You don’t write every detail, just the main ideas: “First, we pick a topic. Then, if everyone agrees, we start research; if not, we pick another.” It’s casual but structured enough to follow. In coding, pseudocode lets you focus on “what” your program does (the logic) before worrying about “how” to write it in Python.

 

How to Write Good Pseudocode

  • Use simple language (e.g., “Ask for name” instead of complicated terms).
  • Include keywords like IF, ELSE, WHILE to show decisions and loops.
  • Indent lines to show which steps belong together (like in the examples above).
  • Be specific enough that someone else could understand your plan, but don’t stress about exact wording.

Fun Activity: Write Pseudocode for Real-Life Scenarios

  • Meme Generator App: Imagine you’re creating a meme generator app. Write pseudocode for this process: The user picks a meme template, adds text, and shares it. Include a decision like “If the text is too long, ask to shorten it.” Share your pseudocode with a classmate—can they understand your plan?
  • Pizza Order System: Write pseudocode for ordering pizza online. Include steps like choosing size, toppings, and payment method, with decisions like “If delivery address is outside area, add extra fee.” Test it by reading it aloud—does it cover all possibilities?

Deeper Dive: Pseudocode vs. Code

Pseudocode is language-agnostic—it’s not tied to Python, Java, or any specific language. For example, in pseudocode, you might write “Ask for age,” but in Python, it becomes age = int(input("Enter your age: ")). Pseudocode focuses on the idea, while code focuses on the implementation. This separation helps beginners avoid getting stuck on syntax early on.

Key Takeaway

Pseudocode is your coding “cheat sheet.” It helps you organize your thoughts and makes writing real code much smoother since you already know what to do. It’s like sketching a drawing before painting the final piece.

 

Section 4: Solving Basic Problems Using Algorithms in Python

Turning Plans into Code

Now that we’ve learned algorithms, flowcharts, and pseudocode, let’s put it all together by writing real Python programs. We’ll solve a variety of simple problems step by step, using the planning tools we’ve discussed. This is where the “rubber meets the road”—turning logic into action! We’ll include more examples to give you plenty of practice.

Problem 1: Even or Odd Number Checker

Goal: Write a program to check if a number (input by the user) is even or odd.

  • Algorithm:
    • Start.
    • Ask the user for a number.
    • If the number divided by 2 has no remainder, it’s even.
    • Otherwise, it’s odd.
    • Print the result.
    • End.
  • Flowchart Description: Start (oval) → Input number (parallelogram) → Decision “Number % 2 == 0?” (diamond) → If Yes, “Print Even” (rectangle) → End (oval); If No, “Print Odd” (rectangle) → End (oval).
  • Pseudocode:

BEGIN

Ask user to input a number

Store input as num

IF num modulo 2 equals 0

Print "The number is even"

ELSE

Print "The number is odd"

END IF

END

 

  • Python Code:

# Get input from user

num = int(input("Enter a number: "))

 

# Check if even or odd using modulo operator

if num % 2 == 0:

print("The number is even")

else:

print("The number is odd")

  • Explanation for Teens: The % (modulo) operator gives the remainder after division. If a number divided by 2 has a remainder of 0, it’s even (like 4 or 10). Otherwise, it’s odd (like 3 or 7). Try running this code with different numbers—see how it works! Bonus: What happens if you enter a negative number? Does it still work?
  • Output Example:
    • Input: 6 → Output: "The number is even"
    • Input: 5 → Output: "The number is odd"

Problem 2: Simple Vending Machine Simulator

Goal: Create a program that simulates a vending machine. The user picks an item (soda, chips, or candy) and pays for it.

  • Algorithm:
    • Start.
    • Show menu (soda = $1.50, chips = $1.00, candy = $0.75).
    • Ask user to choose an item.
    • Ask user to input money.
    • If money is enough, give item and change (if any).
    • If not enough, ask for more money or cancel.
    • End.
  • Flowchart Description: Start (oval) → Show menu (rectangle) → Input choice (parallelogram) → Decision “Valid choice?” (diamond) → If No, “Error, try again” (rectangle) → Back to menu; If Yes, “Input money” (parallelogram) → Decision “Enough money?” (diamond) → If Yes, “Give item and change” (rectangle) → End (oval); If No, “Ask for more or cancel” (rectangle) → End (oval).
  • Pseudocode:

BEGIN

Display menu: Soda ($1.50), Chips ($1.00), Candy ($0.75)

Ask user to choose item (1 for Soda, 2 for Chips, 3 for Candy)

Store choice

IF choice is 1

Set cost to 1.50

Set item to "Soda"

ELSE IF choice is 2

Set cost to 1.00

Set item to "Chips"

ELSE IF choice is 3

Set cost to 0.75

Set item to "Candy"

ELSE

Print "Invalid choice"

Stop

END IF

Ask user to input money

Store money

IF money is greater than or equal to cost

Calculate change as money minus cost

Print "Here's your", item, "and your change is", change

ELSE

Print "Not enough money. Please add more or cancel."

END IF

END

 

  • Python Code:

# Display menu

print("Welcome to the Vending Machine!")

print("1. Soda ($1.50)")

print("2. Chips ($1.00)")

print("3. Candy ($0.75)")

 

# Get user's choice

choice = int(input("Enter your choice (1, 2, or 3): "))

 

# Set cost and item based on choice

if choice == 1:

cost = 1.50

item = "Soda"

elif choice == 2:

cost = 1.00

item = "Chips"

elif choice == 3:

cost = 0.75

item = "Candy"

else:

print("Invalid choice. Please try again.")

exit()

 

# Get money from user

money = float(input("Enter the amount of money ($): "))

 

# Check if enough money is provided

if money &gt;= cost:

change = money - cost

print(f"Here's your {item} and your change is ${change:.2f}")

else:

print("Not enough money. Please add more or cancel.")

  • Explanation for Teens: This program is like running a mini-store! You’re using if-elif-else to handle choices and decisions, just like a real vending machine checks if you’ve paid enough. The .2f in the print statement formats the change to show only 2 decimal places (like real money). Run it and pretend you’re buying snacks—try different amounts of money and see what happens! Bonus: What if you enter a negative amount of money? How could you improve the code to handle that?
  • Output Example:
    • Input: Choice = 1, Money = 2.00 → Output: "Here's your Soda and your change is $0.50"
    • Input: Choice = 3, Money = 0.50 → Output: "Not enough money. Please add more or cancel."

Problem 3: Grade Calculator

Goal: Write a program to calculate a student’s grade based on their score (0-100).

  • Algorithm:
    • Start.
    • Ask user for a test score.
    • Assign a letter grade based on ranges (e.g., 90-100 = A, 80-89 = B, etc.).
    • Print the grade.
    • End.
  • Flowchart Description: Start (oval) → Input score (parallelogram) → Decision “Score &gt;= 90?” (diamond) → If Yes, “Grade = A” (rectangle) → Print grade (rectangle) → End (oval); If No, Decision “Score &gt;= 80?” (diamond) → If Yes, “Grade = B” → Print → End; Continue for C, D, F.
  • Pseudocode:

BEGIN

Ask user to input test score (0-100)

Store input as score

IF score is greater than or equal to 90

Set grade to "A"

ELSE IF score is greater than or equal to 80

Set grade to "B"

ELSE IF score is greater than or equal to 70

Set grade to "C"

ELSE IF score is greater than or equal to 60

Set grade to "D"

ELSE

Set grade to "F"

END IF

Print "Your grade is", grade

END

 

  • Python Code:

# Get test score from user

score = int(input("Enter your test score (0-100): "))

 

# Determine grade based on score

if score &gt;= 90:

grade = "A"

elif score &gt;= 80:

grade = "B"

elif score &gt;= 70:

grade = "C"

elif score &gt;= 60:

grade = "D"

else:

grade = "F"

 

# Display result

print(f"Your grade is {grade}")

  • Explanation for Teens: This program uses multiple conditions to assign a grade, just like teachers do with your tests. It’s a great example of nested decisions (if-elif-else). Run it with different scores to see what grade you’d get! Bonus: How could you add error handling if someone enters a score outside 0-100 (like 150 or -5)?
  • Output Example:
    • Input: 85 → Output: "Your grade is B"
    • Input: 55 → Output: "Your grade is F"

Problem 4: Rock, Paper, Scissors Game

Goal: Create a simple game where the user plays Rock, Paper, Scissors against the computer.

  • Algorithm:
    • Start.
    • Computer randomly picks Rock, Paper, or Scissors.
    • Ask user to pick Rock, Paper, or Scissors.
    • Compare choices to decide winner (Rock beats Scissors, Paper beats Rock, Scissors beats Paper).
    • Print result (win, lose, or tie).
    • End.
  • Flowchart Description: Start (oval) → Computer picks choice (rectangle) → User inputs choice (parallelogram) → Decision “Valid user choice?” (diamond) → If No, “Error, try again” (rectangle) → Back to input; If Yes, Decision “User = Computer?” (diamond) → If Yes, “Tie” (rectangle) → Print result → End; If No, multiple decisions to check who wins → Print result → End.
  • Pseudocode:

BEGIN

Import random module

Set computer_choice to random selection from ["Rock", "Paper", "Scissors"]

Ask user to input choice (Rock, Paper, or Scissors)

Store input as user_choice

Convert user_choice to proper case (e.g., "rock" to "Rock")

IF user_choice is not in ["Rock", "Paper", "Scissors"]

Print "Invalid choice, please try again"

Stop

END IF

Print "Computer chose", computer_choice

IF user_choice equals computer_choice

Print "It's a tie!"

ELSE IF (user_choice is "Rock" AND computer_choice is "Scissors") OR

(user_choice is "Paper" AND computer_choice is "Rock") OR

(user_choice is "Scissors" AND computer_choice is "Paper")

Print "You win!"

ELSE

Print "Computer wins!"

END IF

END

 

  • Python Code:

import random

 

# Computer makes a random choice

choices = ["Rock", "Paper", "Scissors"]

computer_choice = random.choice(choices)

 

# Get user's choice

user_choice = input("Enter your choice (Rock, Paper, Scissors): ").capitalize()

 

# Validate user's input

if user_choice not in choices:

print("Invalid choice, please try again.")

else:

print(f"Computer chose {computer_choice}")

# Determine winner

if user_choice == computer_choice:

print("It's a tie!")

elif (user_choice == "Rock" and computer_choice == "Scissors") or \

(user_choice == "Paper" and computer_choice == "Rock") or \

(user_choice == "Scissors" and computer_choice == "Paper"):

print("You win!")

else:

print("Computer wins!")

  • Explanation for Teens: This game uses the random module to let the computer pick randomly, just like flipping a coin. The logic checks all winning conditions using if-elif-else. Play it multiple times—can you beat the computer? Bonus: How could you add a “Play again?” option to loop the game?
  • Output Example:
    • Input: Rock, Computer: Scissors → Output: "Computer chose Scissors" "You win!"
    • Input: Paper, Computer: Paper → Output: "Computer chose Paper" "It's a tie!"

Problem 5: Simple Countdown Timer

Goal: Write a program that counts down from 10 to 1, then prints “Blast Off!”

  • Algorithm:
    • Start.
    • Set counter to 10.
    • While counter is greater than 0, print counter and decrease by 1.
    • When counter reaches 0, print “Blast Off!”
    • End.
  • Flowchart Description: Start (oval) → Set counter = 10 (rectangle) → Decision “Counter &gt; 0?” (diamond) → If Yes, “Print counter” (rectangle) → “Decrease counter by 1” (rectangle) → Back to decision; If No, “Print Blast Off!” (rectangle) → End (oval).
  • Pseudocode:

BEGIN

Set counter to 10

WHILE counter is greater than 0

Print counter

Decrease counter by 1

END WHILE

Print "Blast Off!"

END

  • Python Code:

# Set starting point

counter = 10

 

# Countdown loop

while counter &gt; 0:

print(counter)

counter -= 1

 

# Final message

print("Blast Off!")

  • Explanation for Teens: This program uses a while loop to repeat an action (printing the counter) until a condition is met (counter reaches 0). It’s like counting down to launch a rocket in a game. Run it and imagine you’re at NASA! Bonus: Can you add a 1-second delay between numbers to make it feel more like a real countdown? (Hint: Look up the time module and sleep() function.)

Blast Off!
