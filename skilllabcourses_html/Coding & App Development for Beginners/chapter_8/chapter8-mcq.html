MCQs

Question 1: What does the term "User Interface (UI)" refer to in app development?

A) The code that makes the app function behind the scenes

B) The process of testing and fixing bugs in the app

C) The visual elements like buttons and text that users interact with

D) The speed at which an app loads on a deviceCorrect Answer: C) The visual elements like buttons and text that users interact with

 

Question 2: What is the primary purpose of Pygame in game development?

A) To design mobile apps using block-based coding

B) To create 2D games using Python with features like graphics and sound

C) To test and debug mobile applications on different devices

D) To build user interfaces for web applicationsCorrect Answer: B) To create 2D games using Python with features like graphics and sound

 

Question 3: In the “Dodge the Squares!” game, what happens when an enemy square reaches the bottom of the screen?

A) The game ends immediately

B) The enemy is removed, and a new one spawns at the top

C) The player’s speed increases automatically

D) The enemy changes colour and moves fasterCorrect Answer: B) The enemy is removed, and a new one spawns at the top

 

Question 4: What is a key advantage of using MIT App Inventor for beginners?

B) It allows coding through drag-and-drop blocks instead of typing syntax
