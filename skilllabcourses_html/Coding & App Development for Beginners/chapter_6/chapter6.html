Chapter 6: Introduction to Web Development with HTML and CSS

 

Section 1: What is Web Development? How Websites Work

Overview: Web development is the process of creating websites and web applications that you use every day. It’s like building a digital house—there’s a structure (HTML), decorations (CSS), and sometimes interactive features (JavaScript, which we’ll touch on later). As a beginner, understanding how websites work is the first step to becoming a web creator.

Detailed Explanation:

  • What is Web Development? Think of web development as crafting a digital space where people can visit, interact, and get information. It involves designing the look, building the structure, and sometimes adding functionality (like buttons or forms). There are three main parts:
    • Frontend: What you see (design and layout, handled by HTML and CSS).
    • Backend: What happens behind the scenes (databases and servers, which we’ll explore in later chapters).
    • Full-Stack: Combining both frontend and backend. For now, we’re focusing on frontend!
  • How Websites Work: When you type a website URL (like ) into your browser, here’s what happens:
    • Your browser sends a request to a server (a powerful computer storing website files).
    • The server sends back files like HTML, CSS, and images.
    • Your browser reads these files and displays the website. Imagine it like ordering food at a restaurant—the browser is you, the server is the kitchen, and the website is the yummy dish delivered to your table!

      •  

  • Key Players in Web Development:
    • Web Developers: People like you who code the site.
    • Web Designers: Focus on how it looks (colours, layouts).
    • Web Hosts: Companies that store your site on servers (like GoDaddy or free options we’ll use).

Relatable Example for Teens: Think about your favourite TikTok page. The videos, colours, and buttons you see are all created with web development tools. HTML builds the skeleton (where things go), CSS makes it look trendy (colours and fonts), and other code makes it interactive (like clicking “like”). Cool, right?

Practical Insight: Websites are everywhere—school portals, gaming sites, online shops. Learning web development lets you create your own digital space to express yourself or even start a small business (like selling custom T-shirt designs online)! Plus, it’s a skill that looks great on college applications or resumes—imagine saying, “I built my own website!”

Fun Element: Did you know the first website ever made (in 1991) is still online? It’s super basic compared to today’s flashy sites, but it started the internet revolution! Search for “first website CERN” to see it—it’s like looking at a digital dinosaur! Compare it to a modern site like Netflix. What differences do you notice?

Section 2: Basics of HTML: Structure and Tags

Overview: HTML (HyperText Markup Language) is the foundation of every webpage. It’s like the blueprint of a house—it tells the browser where to put text, images, and other elements. Let’s learn the basics and write some code!

Detailed Explanation:

  • What is HTML? HTML uses “tags” to define the structure of a webpage. Tags are like containers that hold content (text, pictures, links) and tell the browser what that content is (a heading, a paragraph, etc.). Tags usually come in pairs with an opening tag &lt;tag&gt; and a closing tag &lt;/tag&gt;, though some are self-closing (like &lt;img&gt;).
  • Basic HTML Structure: Every HTML file starts with a specific layout:
    • &lt;!DOCTYPE html&gt;: Tells the browser this is an HTML5 document.
    • &lt;html&gt;: The root element that wraps everything.
    • &lt;head&gt;: Contains metadata (like the title) that isn’t visible on the page.
    • &lt;body&gt;: Contains the visible content (text, images, etc.).
  • Common Tags:
    • &lt;h1&gt; to &lt;h6&gt;: Headings (h1 is the biggest, h6 is smallest).
    • &lt;p&gt;: Paragraphs for text.
    • &lt;img src="image.jpg"&gt;: Adds an image (src is the file path).
    • &lt;a href="link"&gt;: Creates a clickable link (href is the URL).
    • &lt;div&gt;: A container to group elements together.
    • &lt;ul&gt; and &lt;li&gt;: Unordered lists (bullet points).
    • &lt;ol&gt; and &lt;li&gt;: Ordered lists (numbered).
    • &lt;br&gt;: Line break (self-closing, adds a new line).

      •  

Coding Sequence 1: Let’s write a simple HTML page about your favorite game or hobby.

  • Open a text editor (like Notepad on Windows, TextEdit on Mac, or free online editors like Replit or CodePen).
  • Type this code:

&lt;!DOCTYPE html&gt;

&lt;html&gt;

&lt;head&gt;

&lt;title&gt;My Favorite Game&lt;/title&gt;

&lt;/head&gt;

&lt;body&gt;

&lt;h1&gt;Welcome to My Page!&lt;/h1&gt;

&lt;h2&gt;About My Favorite Game: Fortnite&lt;/h2&gt;

&lt;p&gt;I love playing Fortnite because of the cool skins and building mechanics. My best rank is Diamond!&lt;/p&gt;

&lt;img src="https://via.placeholder.com/400x200?text=Fortnite+Image" alt="Fortnite Battle Royale"&gt;

&lt;p&gt;Check out the official site: &lt;a href="https://www.epicgames.com/fortnite"&gt;Fortnite Website&lt;/a&gt;&lt;/p&gt;

&lt;/body&gt;

&lt;/html&gt;

  • Save the file as mygame.html (make sure it ends with .html).
  • Open it in a browser (double-click the file)—you’ll see your webpage! (Note: I’ve used a placeholder image URL from via.placeholder.com since local images require a file on your computer. You can replace it with a real online image URL by right-clicking an image online and copying its address.)

    •  

Practical Explanation for Coding Sequence 1:

  • &lt;h1&gt; makes a big title—great for your main heading.
  • &lt;p&gt; is for regular text, like a description.
  • &lt;img&gt; needs an “alt” attribute (alternative text) so if the image doesn’t load, people (and screen readers for accessibility) know what it’s about.
  • &lt;a&gt; lets you link to other sites—super useful for sharing resources.

Section 3: Styling with CSS: Colours, Fonts, and Layouts

Overview: CSS (Cascading Style Sheets) is what makes websites look awesome. It controls colours, fonts, sizes, and layouts. If HTML is the skeleton, CSS is the outfit—let’s make your webpage pop!

Detailed Explanation:

  • What is CSS? CSS styles your HTML elements by applying rules like “make this text red” or “center this image.” You can write CSS in three ways:
    • Inline (inside an HTML tag with style="").
    • Internal (inside &lt;style&gt; tags in the &lt;head&gt;).
    • External (in a separate .css file linked with &lt;link&gt;). We’ll start with internal CSS for simplicity.
  • Basic CSS Properties:
    • colour: Changes text colour (e.g., colour: blue; or colour: #FF0000; for red in hex code).
    • background-colour: Sets background colour.
    • font-family: Changes text style (e.g., font-family: Arial;).
    • font-size: Adjusts text size (e.g., font-size: 20px;).
    • text-align: Aligns text (e.g., text-align: center;).
    • margin and padding: Controls spacing around elements (margin is outside, padding is inside).
    • border: Adds a border around elements (e.g., border: 1px solid black;).
    • width and height: Sets size of elements like images or divs.
  • CSS Selectors: Rules target elements using tags (h1), classes (.myclass), or IDs (#myid). Classes and IDs are custom names you add to HTML tags for specific styling.

Coding Sequence 1: Let’s style the HTML page we made. Add CSS to make it look trendy. Update your mygame.html like this:

Practical Explanation for Coding Sequence 1:

  • Selectors: In CSS, h1 {} targets all &lt;h1&gt; tags. body {} styles the entire page.
  • Colours: Use names (like “blue”) or hex codes (like #E6F2FF)—you can find hex codes on sites like colour-hex.com.
  • Layout: margin: 0 auto; centers the image. display: block; helps with alignment.
  • Borders: Adding a border to the image makes it stand out like a framed picture. Save and refresh your browser—your page now looks way cooler with colours and centered elements!

Section 4: Creating Your First Webpage (Personal Portfolio or Blog)

Overview: Now that you know HTML and CSS basics, let’s build a full webpage—a personal portfolio or blog. This is your chance to show off who you are or what you love!

Detailed Explanation:

  • What’s a Portfolio/Blog? A portfolio shows your skills, hobbies, or achievements (like art, gaming stats, or school projects). A blog is a space to write about stuff you care about (like music reviews or travel stories). Both are awesome ways to express yourself online.
  • Planning Your Page: Before coding, sketch your idea. Decide:
    • What’s the theme? (e.g., “My Gaming Journey” or “My Art Showcase”)
    • What sections? (e.g., About Me, My Work, Contact)
    • What colours/fonts? (Pick a vibe—dark and mysterious or bright and bubbly)
  • Navigation: Add a simple menu at the top so people can jump to sections (we’ll use anchor links with #).

Practical Explanation for Coding Sequence 1:

  • Classes: CSS uses .header to style specific &lt;div&gt; sections. This helps organize your design.

  • Border and Padding: Adds a neat box around sections for clarity.
  • Personal Touch: Replace placeholders (like [Your Name]) with your info. Use a real photo URL or keep the placeholder. Save and open in a browser—it’s your first full webpage!

  • Personalization: Add real projects or hobbies—replace placeholder text and images with your own content if possible. Refresh your browser—your portfolio now has a slick project showcase!

Fun Element for Teens: Add a “Favorite Memes” section with funny images or GIFs. Or link to your Spotify playlist with a line like “Listen to my vibe here!” Make it a page you’d want to share on social media.

Section 5: Hosting and Sharing Your Webpage Online (Free Tools)

Overview: Building a webpage is awesome, but sharing it with the world is even better! Hosting means putting your files on a server so anyone can see them online. Let’s use free tools to do this.

Detailed Explanation:

  • What is Hosting? Hosting is like renting space on the internet to store your webpage files so others can access them via a URL. Normally, hosting costs money, but there are free options for beginners.
  • Free Hosting Tools:
    • GitHub Pages: A free service to host static websites (HTML/CSS). Perfect for portfolios.
    • Netlify: Another free tool that’s easy to use—just drag and drop your files.
    • Replit: An online coding platform where you can code and host small projects for free.
    • CodePen: Great for testing and sharing small projects (though not full hosting).
  • Domain Names: This is your website’s address (like ). Free hosting often gives a subdomain (like myname.github.io), but you can buy a custom domain later if you want.
  • Why Share Online? Hosting lets friends, family, or even future employers see your work. It’s a digital portfolio that shows off your creativity and skills.

Step-by-Step Guide 1 (Using GitHub Pages):

  • Create a GitHub Account: Go to github.com and sign up (it’s free).
  • Create a Repository: Click the “+” icon, choose “New Repository,” name it username.github.io (replace “username” with your GitHub username), and make it public.
  • Upload Files: Upload your portfolio.html (and any images) to this repository. If you have a separate CSS file or images, upload them in the same folder structure.
  • Enable GitHub Pages: Go to the “Settings” tab of your repository, scroll to “Pages,” and set the source to the “main” branch.
  • Visit Your Site: After a few minutes, go to username.github.io in your browser—your site is live! (If this feels tricky, ask a teacher or friend for help, or try the next option.)

Step-by-Step Guide 2 (Using Netlify):

  • Sign Up for Netlify: Go to netlify.com and create a free account.
  • Create a New Site: Click “New site from Git” or use the “Drag and Drop” option if you don’t use Git.
  • Upload Files: Drag your folder containing portfolio.html (and any images or CSS files) into the upload area.
  • Deploy: Netlify will give you a random URL (like random-name.netlify.app). You can customize it slightly if needed.
  • Visit Your Site: Open the provided URL in your browser—your site is online! (Note: Netlify is super beginner-friendly and doesn’t require learning Git, unlike GitHub Pages.)

Practical Explanation:

  • Hosting makes your site accessible 24/7 to anyone with the link.
  • Free tools have limits (like no custom domains or less storage), but they’re perfect for starting out.
  • Always double-check your links and images work after uploading—sometimes file paths break if images aren’t in the right folder.
  • Safety Tip: Don’t share super personal info (like your home address) on a public site. Keep it fun and general (like hobbies or nicknames).

Coding Sequence (Organizing Files for Hosting): If you have images or a separate CSS file, organize them before uploading. Create a folder called my-portfolio on your computer. Inside it:

  • Save portfolio.html.
  • Create a subfolder called images and save any image files there (e.g., me.jpg).
  • If using external CSS, save it as styles.css in the main folder and link it in HTML with:

&lt;head&gt;

&lt;title&gt;My World - Portfolio&lt;/title&gt;

&lt;link rel="stylesheet" href="styles.css"&gt;

&lt;/head&gt;

Update image paths in HTML to match: &lt;img src="images/me.jpg" alt="My Photo"&gt;. Test locally first, then upload the entire my-portfolio folder to Netlify or GitHub Pages.

Fun Element for Teens: Once your site is live, share the link in your Instagram bio or group chats with a caption like “Check out my website—I’m a coder now! 💻” Imagine your friends reacting to your custom page—it’s like going viral IRL! Bonus: Take a screenshot of your live site and make it your phone wallpaper for ultimate bragging rights.

Challenge 1: After hosting, add a small update to your page (like a new sentence or colour) and re-upload it. Refresh the online link to see your changes live. You’re officially a web developer!

Challenge 2: Create a “Guestbook” section on your site with a fake comment from a friend (e.g., “Wow, this site is epic!”). Style it with a unique background colour and border. Upload the update to your hosted site and check if it works online.
