MCQs

Question 1: What is the best definition of data?

A) A type of computer software

B) Information or facts collected to understand something

C) A set of opinions without evidence

D) A tool used only by scientists

Correct Answer: B) Information or facts collected to understand something

 

Question 2: Which of the following is an example of qualitative data?

A) The temperature today is 28°C.

B) There are 25 students in the classroom.

C) The movie was incredibly funny.

D) I ran 5 kilometres this morning.

Correct Answer: C) The movie was incredibly funny.

 

Question 3: Why is data literacy important in today’s world?

A) It helps you learn how to code.

B) It allows you to understand and question information to make better decisions.

C) It is only useful for getting high grades in school.

D) It teaches you how to use social media.

Correct Answer: B) It allows you to understand and question information to make better decisions.

 

Question 4: What is an example of a data-driven decision in the real world?

A) Guessing what to wear without checking the weather.

B) Using sports statistics to plan a game strategy.

C) Choosing a movie based on a friend’s opinion alone.

D) Deciding to study without looking at test scores.

Correct Answer: B) Using sports statistics to plan a game strategy.

 

Question 5: What is a key concern related to data in the digital age?

A) Data is too difficult to collect.

B) Data is only used by big companies.

C) Privacy issues arise from sharing personal information online.

D) Data cannot be used to solve real-world problems.

Correct Answer: C) Privacy issues arise from sharing personal information online.
